refreshGeofences

@NonNull
abstract fun refreshGeofences(): PendingOperation<SmartGeofencesRefreshResult, SmartGeofencesRefreshError>

Refreshes the list of geofences that the SDK monitors. The SDK obtains the list of geofences that it monitores from the Sentiance Cloud Platform, and refreshes it several times a day. Use this method to initiate a refresh, for instance, when you have created a new geofence directly on the Sentiance Platform, and want it to be immediately monitored by the SDK. Note that refresh requests are throttled to once every 30 seconds.

Throws

SdkException

if the SDK is not initialized.
