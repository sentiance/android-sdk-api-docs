getTimelineEvents

@NonNull
abstract fun getTimelineEvents(@NonNull fromDate: Date, @NonNull toDate: Date): List<Event>

Returns timeline events, such as transport and stationary events, that were captured during the specified date range. The events are ordered from oldest to newest, and are not provisional. See isProvisional to learn more about what a provisional event is.

Events that were captured outside of the specified date range are not returned, even if they were updated during this date range. To get all updates, regardless of when an event was captured, use getTimelineUpdates instead.

Parameters

fromDate

The start date of the date range. The specified date is inclusive.

toDate

The end date of the date range. The specified date is inclusive.

Throws

SdkException

if the SDK is not initialized
