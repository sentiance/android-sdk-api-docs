setTransportTags

open fun setTransportTags(@NonNull tags: Map<String, String>)

Deprecated

Since version 6.29.0

Sets the tags that will be assigned to a detected transport.

The provided tags will be assigned to a transport at the moment the transport ends. When you receive a com.sentiance.sdk.ondevice.api.event.TransportEvent representing the ended transport, it will include these tags.

The supplied tags are persisted and assigned to future transports, even after the app is restarted. By calling this method again, you will replace the tags that will be assigned to future transports.

You can include up to 6 tags (key-value pairs), and each tag component (key or value) must be at most 256 characters. Do not include sensitive personal data in the tags.

Throws SdkException if the SDK is not initialized, NoSentianceUserException if there is no Sentiance user, and IllegalArgumentException if the supplied tags do not adhere to the maximum allowed tag count or character limit.

Deprecated

Use setUserTags instead. Transport tagging is deprecated; this method now delegates to setUserTags, and the resulting tags are surfaced on transports the same way.
