setPotentialVehicleTransportStartListener

open fun setPotentialVehicleTransportStartListener(@Nullable listener: PotentialVehicleTransportStartListener)

Sets a listener that is invoked when a potential vehicle transport start is detected. The listener is invoked once for the duration of the trip.

This feature is experimental.

Throws SdkException if the SDK is not initialized.

Parameters

listener

the listener that will be invoked when a potential vehicle transport start is detected. Pass null to remove the previously set listener.
