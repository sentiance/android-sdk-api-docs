Deprecated

Deprecated: use initialize instead.

Initializes the Sentiance SDK.

This method constructs internal SDK components and prepares the SDK for handling app and system requests. If a Sentiance user does not yet exist on the device, this method triggers user creation on the Sentiance Cloud Cloud Platform, which requires internet connectivity.

During the lifetime of the app process, calling this method again after a successful initialization is not allowed. Doing so is regarded as an error and therefore throws an SdkException at runtime. To reinitialize the SDK with a different configuration or to create a new Sentiance user, first call reset.

All methods in this class (except this method, reset, getInitState, and getVersion) will throw an SdkException when called before initialization has completed.
